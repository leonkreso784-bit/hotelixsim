# AI sloj — plan izgradnje (DEMO korak 4)

**Status:** 🟩 AKTIVAN · **Otvoren:** 2026-10-09 · **Grana:** `gradnja/ai-sloj` · **Rok demoa:** ~14.10. ([ADR-012](../records/DECISIONS.md#adr-012))

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** U lipnju (S1) i srpnju (S2) student može razgovarati s likom (do 6 poruka) i odgovoriti svojim riječima;
AI (Claude) ocijeni odgovor po rubrici od pet kriterija, a jezgra iz te presude obračuna mjesec. Nakon „Zatvori mjesec"
mentor objasni što se dogodilo. Bez ključa ili kad AI zakaže igra radi dalje na rezervama, a zakašnjela presuda
nikad se ne upisuje tiho. Alat `mjerilo` mjeri slaganje AI-ja s Leonovim ocjenama (DEMO §11 t. 7).

**Architecture:** Prvo se popravlja temelj: otisak pravila računa se nad kanonskim `serde_json::Value` spremljenog
snimka, pa nova polja sadržaja (rubrike, likovi) ne kvare postojeće igre. `game` (čist) dobiva nove događaje
(razgovor, slobodan odgovor, presuda, zakašnjela presuda, mentor), provjeru presude (kvaliteta = broj ispunjenih
kriterija, brojke iz najbližeg ponuđenog odgovora) i ulaze za AI. `app` dobiva port `AiPort` i tri nove vrste
poslova u postojećem redu: AI se zove **izvan** zaključavanja igre, a rezultat se upisuje kroz isti `decide` koji
provjerava stanje runde. Novi crate `ai` je tanki HTTP klijent za Claude API (strukturirani izlaz, upute u `prompts/`).

**Tech Stack:** Rust 1.98 (edition 2024) · Axum 0.8 + utoipa 6 · sqlx 0.9 · `reqwest` (samo rustls) · Claude Messages
API (`anthropic-version: 2023-06-01`, `output_config.format` JSON Schema, `fallbacks: "default"`) · Postgres 16.

**Spec:** [ARHITEKTURA.md](../architecture/ARHITEKTURA.md) §8.2–8.4, §9.4, §10 · [DEMO.md](../product/DEMO.md) §1.2,
§1.5, §6.2, §7 (S1, S2), §11 t. 7 · BACKLOG `[korak 4]` · Leonove odluke [ADR-018](../records/DECISIONS.md#adr-018) ·
pretpostavke [ADR-019](../records/DECISIONS.md#adr-019) · tok rada [AGENTI.md](../workflow/AGENTI.md).

```rust
/// Otisak proizvoljnog JSON-a: SHA-256 kanonskog zapisa. `serde_json::Value` drži objekte u `BTreeMap` (bez značajke
/// `preserve_order`), pa su ključevi poredani i otisak ne ovisi o redoslijedu iz datoteke ni o JSONB-u.
pub fn fingerprint_value(v: &serde_json::Value) -> String {
    let bytes = serde_json::to_vec(v).expect("Value se uvijek serijalizira");
    format!("sha256:{:x}", Sha256::digest(&bytes))
}

impl Snapshot {
    // … postojeći `read` i `build` ostaju …

    pub fn to_value(&self) -> serde_json::Value {
        serde_json::to_value(self).expect("snimak nema mapu s ne-tekstualnim ključem pa se uvijek serijalizira")
    }

    /// Snimak iz spremljenog `GameCreated`. Nova polja DTO-a imaju `#[serde(default)]`, pa se stari snimci čitaju.
    pub fn from_value(v: &serde_json::Value) -> Result<Snapshot, ContentError> {
        serde_json::from_value(v.clone())
            .map_err(|e| ContentError::Json(PathBuf::from("<snimak iz dnevnika>"), e.to_string()))
    }

    /// Otisak pravila (`RulesetId`) nad kanonskim `Value` snimka (ADR-015 t. 3, ispravak iz koraka 4).
    pub fn fingerprint(&self) -> String {
        fingerprint_value(&self.to_value())
    }

    /// Otisak iz koraka 3: nad tipiziranim zapisom, redoslijedom polja iz deklaracije. Vrijedi samo za igre stvorene
    /// prije koraka 4; nova polja DTO-a zato imaju `skip_serializing_if`, da stari snimak da isti stari zapis.
    pub fn legacy_fingerprint(&self) -> String {
        let bytes = serde_json::to_vec(self).expect("snimak se uvijek serijalizira");
        format!("sha256:{:x}", Sha256::digest(&bytes))
    }
}
```

```rust
pub fn resolve_job(&self, m: Month, deadline_passed: bool) -> Result<ResolveStep, GameError> {
    // provjera core_version iz Taska 1 ostaje prva
    match self.status(m)? {
        RoundStatus::Resolved => Ok(ResolveStep::Done(Vec::new())),
        RoundStatus::Closing => {
            let pending = self.pending_verdicts(m);
            if !pending.is_empty() && !deadline_passed {
                return Ok(ResolveStep::WaitForVerdicts(pending.len()));
            }
            let mut next = self.clone();
            let mut out = Vec::new();
            for (hotel, code) in pending {
                let ev = next.neutral_verdict(hotel, &code, NEUTRAL_DEADLINE)?;
                next.apply(Recorded { seq: next.last_seq + 1, actor: Actor::System, event: ev.clone() })?;
                out.push((Actor::System, ev));
            }
            let rr = next.resolve_round(m)?;
            next.apply(Recorded { seq: next.last_seq + 1, actor: Actor::System, event: GameEvent::RoundResolved(rr.clone()) })?;
            out.push((Actor::System, GameEvent::RoundResolved(rr)));
            if let Some(n) = next.current_month() {
                out.extend(next.robot_moves(n)?);
            }
            Ok(ResolveStep::Done(out))
        }
        RoundStatus::Open | RoundStatus::Scheduled => Err(corrupt("posao obračuna za rundu koja nije zatvorena")),
    }
}
```

```rust
fn system_events(evs: &[GameEvent]) -> Vec<NewEvent> {

/// Zatvori posao bez događaja (nema više što raditi).
async fn finish(deps: &Deps, game: GameId, claim: JobClaim) -> Result<(), AppError> {
    deps.log
        .decide(game, Box::new(move |_raw: &[RawEvent]| Ok(Decision { finish_job: Some(claim), ..Decision::default() })))

    Ok(())

async fn run_resolve(deps: &Deps, job: &Job) -> Result<(), AppError> {
    let p: ResolvePayload = payload(job)?;
    let m: Month = p.month.into();
    let claim = job.claim();
    let deadline_passed = job.age_secs >= VERDICT_DEADLINE_SECS;
    let g = load_game(deps, job.game_id).await?;
    if !deadline_passed && !g.pending_verdicts(m).is_empty() {
        deps.jobs.defer(claim, VERDICT_WAIT_SECS).await?;
        return Ok(());
    }
    let game_id = job.game_id;
    deps.log
        .decide(game_id, Box::new(move |raw: &[RawEvent]| {
            let g = fold_raw(raw)?;
            let evs = match g.resolve_job(m, deadline_passed)? {
                ResolveStep::Done(evs) => evs,
                ResolveStep::WaitForVerdicts(n) => {
                    return Err(AppError::internal(format!("{n} presuda čeka unutar zaključavanja")));
                }
            };
            let resolved = evs.iter().any(|(_, e)| matches!(e, GameEvent::RoundResolved(_)));
            let mut enqueue = Vec::new();
            if resolved {
                for h in g.hotels.iter().filter(|h| matches!(h.setup.controller, Controller::Human { .. })) {
                    let hotel_id = h.setup.hotel_id;
                    enqueue.push(NewJob {
                        key: debrief_key(game_id, m, hotel_id),
                        kind: DEBRIEF_KIND.to_owned(),
                        game_id,
                        payload: serde_json::to_value(DebriefPayload { hotel_id, month: m.into() })
                            .map_err(|e| AppError::internal(e.to_string()))?,
                    });
                }
            }
            Ok(Decision {
                events: evs.iter().map(|(a, e)| new_event(a, e)).collect(),
                enqueue,
                finish_job: Some(claim),
            })
        }))
        .await?;
    Ok(())
}

async fn run_chat(deps: &Deps, job: &Job) -> Result<(), AppError> {
    let p: ChatPayload = payload(job)?;
    let claim = job.claim();
    let g = load_game(deps, job.game_id).await?;
    if g.status(g.situation_month(&p.situation)?)? != RoundStatus::Open {
        return finish(deps, job.game_id, claim).await;
    }
    let input = g.character_input(p.hotel_id, &p.situation)?;
    let reply = match deps.ai.character(input).await {
        Ok(out) => ReplyBody { text: out.value, source: AiSource::Ai, meta: Some(out.meta) },
        Err(e) if job.attempts < MAX_ATTEMPTS => return Err(AppError::internal(e.to_string())),
        Err(_) => {
            let text = g.content.ai.get(&p.situation)
                .and_then(|a| a.character.as_ref())
                .map(|c| c.fallback_reply.clone())
                .ok_or_else(|| AppError::internal("situacija bez lika"))?;
            ReplyBody { text, source: AiSource::Fallback, meta: None }
        }
    };
    let (hotel, code, n) = (p.hotel_id, p.situation, p.reply_to);
    deps.log
        .decide(job.game_id, Box::new(move |raw: &[RawEvent]| {
            let g = fold_raw(raw)?;
            let ev = g.record_reply(hotel, &code, n, reply)?;
            Ok(Decision { events: system_events(ev.as_slice()), finish_job: Some(claim), ..Decision::default() })
        }))
        .await?;
    Ok(())
}

async fn run_assess(deps: &Deps, job: &Job) -> Result<(), AppError> {
    let p: AssessPayload = payload(job)?;
    let claim = job.claim();
    let g = load_game(deps, job.game_id).await?;
    if !g.response_pending(p.hotel_id, &p.situation)? {
        return finish(deps, job.game_id, claim).await; // presuda već postoji (npr. neutralna nakon roka)
    }
    let input = g.assess_input(p.hotel_id, &p.situation)?;
    let judged = match deps.ai.assess(input).await {
        Ok(out) => g
            .validate_verdict(&p.situation, out.value)
            .map(|v| (v, out.meta))
            .map_err(|e| format!("presuda nije prošla provjeru: {e:?}")),
        Err(e) => Err(e.to_string()),
    };
    let judged = match judged {
        Ok(ok) => Some(ok),
        Err(msg) if job.attempts < MAX_ATTEMPTS => return Err(AppError::internal(msg)),
        Err(_) => None, // zadnji pokušaj: neutralna presuda po pravilu
    };
    let (hotel, code) = (p.hotel_id, p.situation);
    deps.log
        .decide(job.game_id, Box::new(move |raw: &[RawEvent]| {
            let g = fold_raw(raw)?;
            let ev = match judged {
                // VerdictRecorded dok odgovor čeka, VerdictLate ako je u međuvremenu došla neutralna presuda
                Some((v, meta)) => Some(g.record_verdict(hotel, &code, v, meta)?),
                None if g.response_pending(hotel, &code)? => Some(g.neutral_verdict(hotel, &code, NEUTRAL_FAILED)?),
                None => None,
            };
            Ok(Decision { events: system_events(ev.as_slice()), finish_job: Some(claim), ..Decision::default() })
        }))
        .await?;
    Ok(())
}

async fn run_debrief(deps: &Deps, job: &Job) -> Result<(), AppError> {
    let p: DebriefPayload = payload(job)?;
    let m: Month = p.month.into();
    let claim = job.claim();
    let g = load_game(deps, job.game_id).await?;
    if g.hotel(p.hotel_id)?.debriefs.contains_key(&m) {
        return finish(deps, job.game_id, claim).await;
    }
    let input = g.debrief_input(p.hotel_id, m)?;
    let (text, source, meta) = match deps.ai.debrief(input.clone()).await {
        Ok(out) => (out.value, AiSource::Ai, Some(out.meta)),
        Err(e) if job.attempts < MAX_ATTEMPTS => return Err(AppError::internal(e.to_string())),
        Err(_) => (game::fallback_debrief(&input), AiSource::Fallback, None),
    };
    let hotel = p.hotel_id;
    deps.log
        .decide(job.game_id, Box::new(move |raw: &[RawEvent]| {
            let g = fold_raw(raw)?;
            let ev = g.record_debrief(hotel, m, text, source, meta)?;
            Ok(Decision { events: system_events(ev.as_slice()), finish_job: Some(claim), ..Decision::default() })
        }))
        .await?;
    Ok(())
}
```
