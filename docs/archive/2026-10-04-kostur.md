# Kostur od kraja do kraja — plan izgradnje

> **✅ ISPUNJEN 2026-10-04** — referenca, ne izvor istine. Isporuka: [CHANGELOG 0.1.0](../records/CHANGELOG.md); stanje: `CLAUDE.md`.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Lokalno dokazati da su sve veze žive: Rust jezgra (kocka s „zlatnim" vektorima, pet indeksa i profili) → PostgreSQL (dnevnik događaja) → Axum API s OpenAPI opisom → generirani TypeScript klijent → jedan React ekran koji prikazuje stanje baze i pet indeksa profila.

**Architecture:** Heksagonalno (ARHITEKTURA §6.2): `engine` i `sim-hotel` su čiste knjižnice bez I/O-a, sata i vanjske slučajnosti. `app` definira port `SystemStatus`, `store` ga implementira nad Postgresom, `api` je Axum + utoipa, `server` je jedini kompozicijski korijen. Sučelje (`apps/web`) zove API isključivo kroz klijent generiran iz `openapi.json`.

**Tech Stack:** Rust 1.98 (izdanje 2024) · Axum 0.8.9 · utoipa 6.0.0 + utoipa-axum 0.3.0 · SQLx 0.9.0 · Tokio 1 · PostgreSQL 16 (lokalni Windows servis) *(izmijenjeno pri gradnji: zaseban klaster na priključku 5433, `scripts/baza.sh`)* · Node 24 · pnpm 10.34.6 (preko corepacka) · TypeScript 5.9.3 · React 19.3 · Vite 8.3.2 · TanStack Query 5.104.1 · openapi-typescript 7.13.0 + openapi-fetch 0.17.0 · Vitest 5.0.3 · Biome 2.5.15

**Spec:** [docs/ARHITEKTURA.md](../architecture/ARHITEKTURA.md) v2 (§5, §6, §7.2, §9.1, §11, §14, §15, §20 korak 1) · [docs/DEMO.md](../product/DEMO.md) (§4 indeksi, §5 profili) · [docs/istrazivanje/RUST_ALATI_2026-10.md](../research/RUST_ALATI_2026-10.md)

## Global Constraints

- Sve radi **lokalno**; ništa ne ovisi o Railwayu (ARHITEKTURA §14). **Nema pusha bez Leonovog izričitog OK-a.**
- `#![forbid(unsafe_code)]` u svim našim paketima (preko `[workspace.lints.rust] unsafe_code = "forbid"`).
- `[profile.release] overflow-checks = true` u korijenskom `Cargo.toml`.
- `engine` i `sim-hotel` ne smiju (ni tranzitivno) ovisiti o: `tokio`, `sqlx`, `reqwest`, `rand`, `rand_core`, `getrandom`, `chrono`, `time`, `axum`, `hyper`. U njima su zabranjeni `HashMap`, `HashSet`, `SystemTime::now`, `Instant::now`, aritmetika s pomičnim zarezom i neprovjerena cjelobrojna aritmetika (clippy `float_arithmetic`, `arithmetic_side_effects`).
- Indeks se u jezgri drži u **stotinkama**: `0..=10_000` znači 0,00–100,00 (DEMO §4, ARHITEKTURA §7.2: bez decimalnih brojeva u jezgri).
- OpenAPI izlaz mora biti verzija **3.1.0** (openapi-typescript čita samo 3.0 i 3.1).
- TypeScript ostaje na **5.9.3**: `openapi-typescript@7.13.0` ima `peerDependencies: { typescript: "^5.x" }`.
- pnpm se pokreće kao `corepack pnpm …` (verzija iz `packageManager`). pnpm 12 ne radi preko corepacka 0.34 na ovom stroju.
- Portovi: API `127.0.0.1:8080`, Vite `5173`. Ne koristiti 5050, 5060, 5061.
- Tekst u sučelju samo kroz `packages/i18n` (ARHITEKTURA K9), nikad zapisan u komponentu.
- Generirane datoteke (`openapi.json`, `packages/api-client/src/schema.d.ts`) su u gitu s LF završecima (`.gitattributes`).
- Shell zamke ovog stroja (Windows + Git Bash): commit poruke uvijek kroz `git commit -F <datoteka>`, nikad `-m "…"` s backtickom ili `$(…)`; izričite putanje u `git add`, nikad `git add -A`; `echo EXIT=$?` odmah iza gole naredbe, ne iza cijevi.

## Review Focus

1. **utoipa 6 može dati OpenAPI 3.2** — tada TS generator pukne tiho ili glasno. Očekivano: `openapi.json` ima `"openapi": "3.1.0"`; test u Tasku 5 to zaključava.
2. **Baza nije dostupna** (servis ugašen, kriva lozinka, tablica ne postoji) — očekivano: server se ipak pokrene, `/v1/health` vrati **503** s `"database": "error"`, ništa ne panicira. Testovi s lažnim portom u Tasku 5 + ručna provjera u Tasku 8.
3. **Nepoznat profil u putanji** (`/v1/demo/profiles/D/indices`, `/v1/demo/profiles/a/indices`) — očekivano: **404** `application/problem+json` s `code: "unknown_profile"`, ne 500. Test u Tasku 5.
4. **Jezgra tiho povuče zabranjenu ovisnost ili `HashMap`** — očekivano: `scripts/check-core-deps.mjs` i clippy padaju. Obrnuta provjera (mutacija) u Tasku 1 dokazuje da brana stvarno mjeri.
5. **CRLF / nestabilna generacija na Windowsu** — očekivano: dvije uzastopne generacije `openapi.json` i `schema.d.ts` daju bajt-identičan izlaz, a `git diff` ostaje prazan. Provjera `check:api` u Tasku 6.
