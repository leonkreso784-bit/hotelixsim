# Kostur od kraja do kraja — plan izgradnje

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Lokalno dokazati da su sve veze žive: Rust jezgra (kocka s „zlatnim" vektorima, pet indeksa i profili) → PostgreSQL (dnevnik događaja) → Axum API s OpenAPI opisom → generirani TypeScript klijent → jedan React ekran koji prikazuje stanje baze i pet indeksa profila.

**Tech Stack:** Rust 1.98 (izdanje 2024) · Axum 0.8.9 · utoipa 6.0.0 + utoipa-axum 0.3.0 · SQLx 0.9.0 · Tokio 1 · PostgreSQL 16 (lokalni Windows servis) · Node 24 · pnpm 10.34.6 (preko corepacka) · TypeScript 5.9.3 · React 19.3 · Vite 8.3.2 · TanStack Query 5.104.1 · openapi-typescript 7.13.0 + openapi-fetch 0.17.0 · Vitest 5.0.3 · Biome 2.5.15

- [ ] **Step 3: Izvedba — `crates/engine/src/rng.rs`**

```rust
//! Kocka: SplitMix64 (Vigna), neovisni tokovi iz sjemena. Ne ovisi o vanjskoj biblioteci, jer `rand`
//! dopušta da nova manja verzija promijeni niz brojeva (istrazivanje/RUST_ALATI_2026-10.md).
//! Sva `wrapping_*` aritmetika ovdje je namjerna: dio je definicije algoritma.

const GOLDEN_GAMMA: u64 = 0x9E37_79B9_7F4A_7C15;
const FNV_OFFSET: u64 = 0xcbf2_9ce4_8422_2325;
const FNV_PRIME: u64 = 0x0000_0100_0000_01b3;

fn finalize(mut z: u64) -> u64 {
    z = (z ^ (z >> 30)).wrapping_mul(0xBF58_476D_1CE4_E5B9);
    z = (z ^ (z >> 27)).wrapping_mul(0x94D0_49BB_1331_11EB);
    z ^ (z >> 31)
}

fn mix64(x: u64) -> u64 {
    finalize(x.wrapping_add(GOLDEN_GAMMA))
}

/// FNV-1a 64 nad UTF-8 bajtovima; služi za stabilne oznake tokova (npr. `label("trigger:T1")`).
pub fn label(s: &str) -> u64 {
    s.bytes().fold(FNV_OFFSET, |h, b| (h ^ u64::from(b)).wrapping_mul(FNV_PRIME))
}

/// Ponovljiva kocka. Isto sjeme i iste oznake daju isti niz na svakom računalu.
#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Rng {
    state: u64,
}

impl Rng {
    pub fn from_seed(seed: u64) -> Self {
        Self { state: seed }
    }

    /// Neovisan tok izveden iz sjemena igre i oznaka, npr. `(runda, hotel, label("trigger:T1"))`.
    pub fn derive(seed: u64, labels: &[u64]) -> Self {
        let state = labels.iter().fold(mix64(seed), |s, l| mix64(s ^ l));
        Self { state }
    }

    pub fn next_u64(&mut self) -> u64 {
        self.state = self.state.wrapping_add(GOLDEN_GAMMA);
        finalize(self.state)
    }

    /// Jednoliko iz `[lo, hi)`, bez pristranosti (odbacivanje ispod praga).
    pub fn range(&mut self, lo: u64, hi: u64) -> u64 {
        assert!(lo < hi, "range: potrebno lo < hi (lo={lo}, hi={hi})");
        let span = hi.checked_sub(lo).expect("lo < hi");
        let threshold = span.wrapping_neg().checked_rem(span).expect("span > 0");
        loop {
            let r = self.next_u64();
            if r >= threshold {
                let offset = r.checked_rem(span).expect("span > 0");
                return lo.checked_add(offset).expect("lo + offset < hi");
            }
        }
    }

    /// Vjerojatnost u baznim bodovima: 0 = nikad, 10_000 = uvijek.
    pub fn chance_bp(&mut self, bp: u32) -> bool {
        assert!(bp <= 10_000, "chance_bp: potrebno bp <= 10000 (bp={bp})");
        self.range(0, 10_000) < u64::from(bp)
    }
}
```

```rust
//! Pet indeksa 0–100 (DEMO §4). U jezgri se drže u stotinkama: 0..=10_000.

#[derive(Clone, Copy, Debug, PartialEq, Eq, PartialOrd, Ord, Hash)]
pub enum Index {
    Guests,
    Reviews,
    Staff,
    Operations,
    Finance,
}

impl Index {
    pub const ALL: [Index; 5] = [Index::Guests, Index::Reviews, Index::Staff, Index::Operations, Index::Finance];

    /// Stabilan kod za API i prijevode; nikad se ne mijenja.
    pub fn code(self) -> &'static str {
        match self {
            Index::Guests => "G",
            Index::Reviews => "R",
            Index::Staff => "Z",
            Index::Operations => "O",
            Index::Finance => "F",
        }
    }

    fn position(self) -> usize {
        match self {
            Index::Guests => 0,
            Index::Reviews => 1,
            Index::Staff => 2,
            Index::Operations => 3,
            Index::Finance => 4,
        }
    }
}

#[derive(Clone, Copy, Debug, PartialEq, Eq, PartialOrd, Ord)]
pub struct IndexValue(u16);

impl IndexValue {
    pub const MAX_HUNDREDTHS: u16 = 10_000;

    pub fn new(hundredths: u16) -> Option<Self> {
        (hundredths <= Self::MAX_HUNDREDTHS).then_some(Self(hundredths))
    }

    pub fn hundredths(self) -> u16 {
        self.0
    }
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct IndexSet([IndexValue; 5]);

impl IndexSet {
    /// Vrijednosti u redoslijedu `Index::ALL` (G, R, Z, O, F).
    pub fn from_hundredths(values: [u16; 5]) -> Option<Self> {
        let mut out = [IndexValue(0); 5];
        for (slot, v) in out.iter_mut().zip(values) {
            *slot = IndexValue::new(v)?;
        }
        Some(Self(out))
    }

    pub fn get(&self, index: Index) -> IndexValue {
        self.0[index.position()]
    }

    pub fn iter(&self) -> impl Iterator<Item = (Index, IndexValue)> + '_ {
        Index::ALL.into_iter().map(|i| (i, self.get(i)))
    }

    pub fn total_hundredths(&self) -> u32 {
        self.0.iter().map(|v| u32::from(v.0)).sum()
    }
}
```

```rust
use std::time::Duration;

use app::{BoxFut, StatusError, SystemStatus};
use sqlx::PgPool;
use sqlx::postgres::PgPoolOptions;

#[derive(Clone)]
pub struct Store {
    pool: PgPool,
}

impl Store {
    /// Ne spaja se odmah: server se pokrene i kad baza nije dostupna, a zdravlje to javi (503).
    pub fn connect_lazy(url: &str) -> Result<Self, sqlx::Error> {
        let pool = PgPoolOptions::new().acquire_timeout(Duration::from_secs(3)).connect_lazy(url)?;
        Ok(Self { pool })
    }

    pub fn from_pool(pool: PgPool) -> Self {
        Self { pool }
    }

    pub async fn migrate(&self) -> Result<(), sqlx::migrate::MigrateError> {
        sqlx::migrate!("./migrations").run(&self.pool).await
    }

    pub async fn count_events(&self) -> Result<i64, sqlx::Error> {
        sqlx::query_scalar!(r#"SELECT COUNT(*) AS "count!" FROM events"#).fetch_one(&self.pool).await
    }
}

impl SystemStatus for Store {
    fn events_count(&self) -> BoxFut<'_, Result<i64, StatusError>> {
        Box::pin(async move { self.count_events().await.map_err(|e| StatusError(e.to_string())) })
    }
}
```

```rust
//! Greške u obliku application/problem+json (RFC 9457), s kodom koji sučelje prevodi.

use axum::http::{StatusCode, header};
use axum::response::{IntoResponse, Response};
use serde::Serialize;
use utoipa::ToSchema;

#[derive(Serialize, ToSchema)]
pub struct Problem {
    #[serde(rename = "type")]
    pub kind: &'static str,
    pub title: &'static str,
    pub status: u16,
    pub code: &'static str,
}

impl Problem {
    pub fn not_found(title: &'static str, code: &'static str) -> Self {
        Self { kind: "about:blank", title, status: 404, code }
    }
}

impl IntoResponse for Problem {
    fn into_response(self) -> Response {
        let status = StatusCode::from_u16(self.status).unwrap_or(StatusCode::INTERNAL_SERVER_ERROR);
        let body = serde_json::to_vec(&self).unwrap_or_default();
        (status, [(header::CONTENT_TYPE, "application/problem+json")], body).into_response()
    }
}
```

```rust
//! Kompozicijski korijen: jedino mjesto gdje se sve spaja (ARHITEKTURA §6.2).
//! Naredbe: `serve` (zadano), `migrate`, `openapi`.

use std::sync::Arc;

use anyhow::{Context, bail};

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let cmd = std::env::args().nth(1).unwrap_or_else(|| "serve".to_owned());
    match cmd.as_str() {
        "openapi" => {
            print!("{}", api::openapi_json());
            Ok(())
        }
        "migrate" => {
            let store = store::Store::connect_lazy(&database_url()?)?;
            store.migrate().await.context("migracija nije uspjela")?;
            println!("migracije primijenjene");
            Ok(())
        }
        "serve" => serve().await,
        other => bail!("nepoznata naredba: {other} (serve | migrate | openapi)"),
    }
}

fn database_url() -> anyhow::Result<String> {
    std::env::var("DATABASE_URL").context("nedostaje DATABASE_URL (vidi .env.example)")
}

async fn serve() -> anyhow::Result<()> {
    tracing_subscriber::fmt()
        .with_env_filter(tracing_subscriber::EnvFilter::try_from_default_env().unwrap_or_else(|_| "info".into()))
        .init();
    let addr = std::env::var("HOTELIXSIM_ADDR").unwrap_or_else(|_| "127.0.0.1:8080".to_owned());
    let store = store::Store::connect_lazy(&database_url()?)?;
    let app = api::router(api::AppState { status: Arc::new(store) });
    let listener = tokio::net::TcpListener::bind(&addr)
        .await
        .with_context(|| format!("ne mogu slušati na {addr} (je li port zauzet?)"))?;
    tracing::info!("HotelixSim API sluša na http://{addr}");
    axum::serve(listener, app)
        .with_graceful_shutdown(async {
            let _ = tokio::signal::ctrl_c().await;
        })
        .await?;
    Ok(())
}
```

`apps/web/src/App.tsx`:

```tsx
import type { ApiClient } from "@hotelixsim/api-client";
import { type MessageKey, t } from "@hotelixsim/i18n";
import { useQuery } from "@tanstack/react-query";
import { formatIndex } from "./format";

const PROFILE = "C";

export function App({ client }: { client: ApiClient }) {
  const health = useQuery({
    queryKey: ["health"],
    queryFn: async () => {
      const { data, error, response } = await client.GET("/v1/health");
      if (data) return data;
      if (response.status === 503 && error) return error;
      throw new Error(`health ${response.status}`);
    },
  });
  const indices = useQuery({
    queryKey: ["indices", PROFILE],
    queryFn: async () => {
      const { data, response } = await client.GET("/v1/demo/profiles/{profile}/indices", {
        params: { path: { profile: PROFILE } },
      });
      if (!data) throw new Error(`indices ${response.status}`);
      return data;
    },
  });

  return (
    <main>
      <h1>{t("app.title")}</h1>
      <p>
        {health.isPending
          ? t("status.loading")
          : health.isError
            ? t("status.api.error")
            : health.data.database === "ok"
              ? t("status.db.ok")
              : t("status.db.error")}
      </p>
      {health.data?.events != null && (
        <p>
          {t("status.events")}: {health.data.events}
        </p>
      )}
      <h2>
        {t("profile.heading")} {PROFILE}
      </h2>
      <ul>
        {indices.data?.indices.map((i) => (
          <li key={i.code}>
            <span>{t(`index.${i.code}` as MessageKey)}</span> <strong>{formatIndex(i.hundredths)}</strong>
          </li>
        ))}
      </ul>
    </main>
  );
}
```

Napomena za izvođača: ako generirani tip za 503 odgovor ne daje `error` istog oblika kao `data`, zadrži ponašanje iz testova (503 → „Baza: nije dostupna") i prilagodi samo tipiziranje; razlog zapiši u izvještaj.
